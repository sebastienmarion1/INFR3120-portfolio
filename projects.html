My Projects

Snake Game

In my last year of high school in 2023, I created a simple version of the Google Snake game using Python 3.10.8 to code it and Pygame as my engine to run the game. This was built over the course of a few weeks as a final project for my grade 12 Introduction to Computer Science class. The game features a menu which explains how to play along with the controls.

Healthcare Appointment System

This program was something I contributed to in a group project for my Object Oriented Programming course in 2025, built as a Python console application. Users are able to book, view, edit, and cancel appointments between patients and doctors. It uses many fundamental Python concepts such as classes, inheritance, polymorphism and file handling.

Tower Defense Project

The goal of this project was to develop a beginner friendly tower defense game in Processing 3.5.4 in Python mode to teach to children aged 8-10 years old. This game features moving enemies, a health system, towers, and a scoring system. I built this project in November 2025, to then teach to students in the following month. After completing the base game around March of 2026, I added some extra features such as background music, sound effects, and a pause button.

Automotive Energy Efficiency Report

This report was co authored with Shahzaib Amir in 2024 as part of our Technical Communications course. It was focused on the reasearch of energy efficient robots, smart energy management, renewable energy, and AI assisted workflows. My focus was on the smart energy management and renewable energy aspects. This project was done in aproximately 4 weeks.

Introduction to Networking II Final Project

This Introduction to Networking II group project focused on building a simulated corporate network in Cisco Packet Tracer across four locations. Throughout this project, I applied concepts I learned in class such as VLANs, inter-VLAN routing, OSPF, BGP, and others to build and troubleshoot this network.
